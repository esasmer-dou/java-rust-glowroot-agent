# java-rust-glowroot-agent 0.5.4

[English](0.5.4.md) | [Türkçe](0.5.4.tr.md)

`0.5.4`, performans doğrulamasını zorunlu bir release sınırı haline getirir. `0.5.3` ile eklenen
sınırlı collector reconnect davranışı korunur. Java API'leri, business logic, REST ABI `29` ve
Glowroot ABI `6` değişmez.

## Kullanıcı Ne Kazanır?

- Release, eski bir framework checkout'u yerine Rust-Java REST `4.6.2` ile test edilir.
- Aynı release commit'i için başarılı Production Gate yoksa Maven package ve GitHub dosyaları
  yayımlanamaz.
- Başarılı koşuda Spring Boot ve Rust-Java REST kanıt dosyalarının bulunması gerekir. Süresi dolmuş
  veya eksik kanıt kabul edilmez.
- Spring MVC, WebFlux ve web olmayan test uygulamaları release commit'i ile aynı agent sürümünü
  kullanmak zorundadır. Eski veya kod içine sabitlenmiş agent sürümü release'e izin vermez.
- Her baseline/candidate çifti otomatik seçilen aynı CPU grubunda çalışır. Çalışma sırası her çiftte
  ters çevrilir. Böylece iki taraf aynı kapasiteyi kullanır ve zaman sırasının etkisi azalır.
- Release A/B işleri sabitlenmiş GitHub-hosted Linux image'larında çalışır. Ortak doğruluk kontrolü
  geçtikten sonra Spring Boot ve Rust-Java REST matrisleri paralel başlar. Bir matrisin bitmesi için
  diğerinin beklemesi gerekmez.
- Ölçülen application bir fiziksel CPU grubunun tamamını tek başına kullanır. Yük üreticisi diğer
  grubun bir mantıksal CPU'sunu; collector ve test yöneticisi kardeş CPU'yu kullanır. Bu sınırlı
  topoloji kanıt dosyasına yazılır. Matristen önce 30 saniyelik sakin host kontrolü yapılır.
  Gürültülü veya kararsız runner performans iddiası üretemez.
- Agent kapalı/açık karşılaştırması mevcut sınırları korur: faydalı `200` RPS kaybı en fazla `%2`,
  p99 artışı en fazla `%10`, process/cgroup memory artışı en fazla `3 MiB`, kararlı endpoint'lerde
  hata oranı artışı sıfır ve ek exporter thread sayısı en fazla birdir.
- Embedded REST protokol kontrolü sınırlı ve deterministik bir curl istek grubu kullanır. Release
  öncesinde Web aggregate, gauge, slow trace, Java-agent başlangıcı ve collector kapalıyken fail-open
  davranışlarının tamamı kanıtlanır.

## Bağımlılık

```xml
<dependency>
  <groupId>com.reactor</groupId>
  <artifactId>java-rust-glowroot-spring-boot-starter</artifactId>
  <version>0.5.4</version>
</dependency>
```

Embedded runtime için Rust-Java REST `4.6.2` kullanın. Spring Boot uygulamasında `0.5.4` paketindeki
DLL/SO dosyasını kullanın. Bu JAR'ı daha eski bir native dosya ile birlikte kullanmayın.

## Release Sınırı

CI; doğruluğu, artifact sınırlarını ve native provenance bilgisini doğrular. Ayrı Production Gate;
aynı release commit'i üzerinde RSS, p99, faydalı RPS, hata oranı ve thread sayısında gerileme
olmadığını ölçer. Release iki kontrolü de zorunlu tutar. Eksik, başarısız, eski commit'e ait veya
süresi dolmuş bir Production Gate sonucu Maven deploy ve GitHub dosya yayınından önce işlemi durdurur.
