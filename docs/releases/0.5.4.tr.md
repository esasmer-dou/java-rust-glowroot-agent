# java-rust-glowroot-agent 0.5.4

[English](0.5.4.md) | [Türkçe](0.5.4.tr.md)

`0.5.4`, performans doğrulamasını zorunlu bir release sınırı haline getirir. `0.5.3` ile eklenen
sınırlı collector reconnect davranışı korunur. Java API'leri, business logic, REST ABI `29` ve
Glowroot ABI `6` değişmez.

## Kullanıcı Ne Kazanır?

- Release, eski bir framework checkout'u yerine Rust-Java REST `4.6.2` ile test edilir.
- Aynı release commit'i için başarılı Production Gate yoksa Maven package ve GitHub dosyaları
  yayımlanamaz.
- Başarılı koşuda Spring Boot ve Rust-Java REST kanıt dosyalarının bulunması gerekir. Süresi dolmuş
  veya eksik kanıt kabul edilmez.
- Agent kapalı/açık karşılaştırması mevcut sınırları korur: faydalı `200` RPS kaybı en fazla `%2`,
  p99 artışı en fazla `%10`, process/cgroup memory artışı en fazla `3 MiB`, kararlı endpoint'lerde
  hata oranı artışı sıfır ve ek exporter thread sayısı en fazla birdir.

## Bağımlılık

```xml
<dependency>
  <groupId>com.reactor</groupId>
  <artifactId>java-rust-glowroot-spring-boot-starter</artifactId>
  <version>0.5.4</version>
</dependency>
```

Embedded runtime için Rust-Java REST `4.6.2` kullanın. Spring Boot uygulamasında `0.5.4` paketindeki
DLL/SO dosyasını kullanın. Bu JAR'ı daha eski bir native dosya ile birlikte kullanmayın.

## Release Sınırı

CI; doğruluğu, artifact sınırlarını ve native provenance bilgisini doğrular. Ayrı Production Gate;
RSS, p99, faydalı RPS, hata oranı ve thread sayısında gerileme olmadığını ölçer. Release artık iki
kontrolün de geçmesini zorunlu tutar.
