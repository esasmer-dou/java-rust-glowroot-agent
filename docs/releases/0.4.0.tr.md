# java-rust-glowroot-agent 0.4.0

[English](0.4.0.md) | [Türkçe](0.4.0.tr.md)

`0.4.0`, desteklenen bütün Spring web runtime'larına aynı sınırlı HTTP telemetri sözleşmesini verir.
Agent uygulama sunucusu eklemez ve seçmez.

## Kullanıcı Ne Kazanır?

- Spring MVC uygulamasına tek starter eklenir. Mevcut sunucu otomatik algılanır.
- Tomcat context Valve, Jetty completion RequestLog, Undertow ise exchange completion listener
  kullanır. Üçü de senkron, asenkron, eşlenen durum, exception, `404`, sınırlı route, yavaş istek ve
  hata telemetrisini destekler.
- WebFlux ayrı ve küçük bir artifact olarak kalır. Sınırlı tek WebFilter kullanır.
- WebFlux adaptörü önce uygulamanın terminal sinyalini tamamlar, sonra sınırlı telemetri olayını
  kaydeder. Böylece yanıtın kritik yolundaki callback işi azalır. Son durum, normalize route,
  asenkron tamamlanma ve hata sayımı korunur.
- Web olmayan Spring Boot worker'ları yalnız `java-rust-glowroot-spring-runtime` kullanabilir. Servlet,
  MVC, embedded server veya WebFlux dependency'si gerekmez.
- Toplama, protobuf encode, reconnect, sınırlı kuyruklar ve kaynak bırakma ortak Rust runtime'ında,
  izole exporter thread'i üzerinde çalışır.
- Java request thread'leri exception mesajını veya stack satırlarını okumaz. Rust'a yalnız sınırlı
  ve zayıf bir referans iletir. İsteğe bağlı hata ayrıntısını mevcut trace kapasitesi içinde izole
  exporter çıkarır. GC veya backpressure önce davranırsa ayrıntı güvenli biçimde atılır.
- Agent Tomcat, Jetty, Undertow, Reactor Netty veya Servlet motoru eklemez. Sunucu API bağımlılıkları
  izole adaptör modüllerinde `provided` ve `optional` olarak kalır.
- Sunucuya özel açma-kapama ayarı yoktur. `reactor.glowroot.enabled=true` ve
  `reactor.glowroot.spring.enabled=true` olduğunda desteklenen sunucu kendi optimize adaptörünü açar.

## Spring MVC Kurulumu

```xml
<dependency>
  <groupId>com.reactor</groupId>
  <artifactId>java-rust-glowroot-spring-boot-starter</artifactId>
  <version>0.4.0</version>
</dependency>
```

Uygulamanın normal Tomcat, Jetty veya Undertow seçimini koruyun. Agent için sunucu bağımlılığı ya da
sunucuya özel property eklemeyin.

| Runtime | Açılan adaptör | Agent'ın eklediği sunucu motoru |
| --- | --- | --- |
| Spring MVC + Tomcat | `tomcat-valve` | Yok |
| Spring MVC + Jetty | `jetty-request-log` | Yok |
| Spring MVC + Undertow | `undertow-completion-listener` | Yok |

## WebFlux Kurulumu

```xml
<dependency>
  <groupId>com.reactor</groupId>
  <artifactId>java-rust-glowroot-spring-webflux-adapter</artifactId>
  <version>0.4.0</version>
</dependency>
```

Uygulama `spring-boot-starter-webflux` bağımlılığını kendisi sağlar ve reaktif sunucusunu kendisi
seçer.

## Web Olmayan Spring Boot Kurulumu

Kafka worker, scheduler, batch process, komut satırı uygulaması veya yalnız veritabanı kullanan
Spring Boot servisi için sadece runtime paketini ekleyin:

```xml
<dependency>
  <groupId>com.reactor</groupId>
  <artifactId>java-rust-glowroot-spring-runtime</artifactId>
  <version>0.4.0</version>
</dependency>
```

```properties
spring.main.web-application-type=none
reactor.glowroot.enabled=true
reactor.glowroot.profile=jvm
reactor.glowroot.collector.address=http://glowroot-collector:8181
reactor.glowroot.agent.id=invoice-worker::pod-1
reactor.glowroot.application.name=invoice-worker
```

Ana Spring Boot starter da çalışır. Ancak yalnız runtime paketi en küçük classpath'i sağlar. Telemetri
açıldığında Spring process-scoped tek bir native runtime ve izole tek Rust exporter thread'i
oluşturur. Telemetri kapalıysa bean oluşturulmaz, native kütüphane yüklenmez ve exporter state'i
ayrılmaz.

| Profil | Web olmadan alınan veri |
| --- | --- |
| `micro` | Process RSS, işletim sistemi thread sayısı, exporter/reconnect/drop durumu |
| `jvm` | `micro` verisine ek olarak heap, non-heap, memory pool, GC sayısı ve GC süresi |
| `sql` | `micro` verisine ek olarak açıkça kaydedilen SQL süre, hata ve satır toplamları |
| `full` | JVM ölçümleri, açık SQL ölçümleri ve sınırlı hata stack bilgisi |
| `diagnostic` | `full` verisine ek olarak yetkili thread dump, heap histogram ve heap dump komutları |

Kafka topic, scheduler job, batch step, rastgele Java metodu ve JDBC çağrısı otomatik olarak bulunmaz
ve weave edilmez. Process/JVM verisi otomatik alınır. SQL süresi tekrar kullanılan açık bir
`NativeTelemetry.SqlStatement` tanımıyla kaydedilir. İsteğe bağlı `-javaagent` bootstrap yalnız erken
property değerlerini aktarır; runtime dependency'sinin yerini almaz.

## Doğrulama

Release kaynağında Tomcat, Jetty, Undertow ve Reactor Netty için executable OpenJ9 uyumluluk gate'i
vardır. Gate; senkron `200`, asenkron `200`, `500`, `404`, native route kaydı, seçilen adaptör kimliği
ve kısa yük altında sıfır non-2xx sonucunu doğrular. Ayrı dependency gate'i hem Maven runtime tree'yi
hem executable JAR içindeki `BOOT-INF/lib` dizinini inceler. Seçilmeyen sunucu motoru bulunursa build
durur.
Gerçek bir `WebApplicationType.NONE` gate'i de MVC bean'i veya web runtime dependency'si olmadan
native JVM/SQL telemetrisinin başladığını ayrıca doğrular.

Uyumluluk sonuçları sunucuları hız bakımından sıralamaz. Production agent maliyeti, aynı sunucunun
telemetri kapalı ve açık varyantlarının eşleştirilmiş sonucu üzerinden değerlendirilmelidir.

### Stable A/B Gate

Runtime, Semeru OpenJ9 21 ile telemetri kapalı ve açık process çiftleri rastgele sırada çalıştırılarak
ölçüldü. Her WebFlux hücresi `60 saniye` sürdü. Böylece her açık telemetri ölçümünde en az bir gerçek
exporter penceresi çalıştı. Fail-open düzeltmesinden sonra en hassas raw JSON hücresi son kaynak
üzerinde yeniden doğrulandı.

| Runtime ve yük | Kullanışlı RPS farkı | p99 farkı | Process RSS farkı | Non-2xx |
| --- | ---: | ---: | ---: | ---: |
| Tomcat, küçük JSON, c256 | `%1,91 azalma` | `%5,43 artış` | `+2,23 MiB` | `0` |
| WebFlux, küçük JSON, c64 | `%1,22 azalma` | `%6,18 azalma` | En fazla `+2,11 MiB` | `0` |
| WebFlux, küçük JSON, c256 | `%0,27 artış` | `%7,58 azalma` | En fazla `+2,11 MiB` | `0` |
| WebFlux, raw JSON, c64, son kaynak | `%1,23 artış` | `%5,97 azalma` | `+0,82 MiB` | `0` |
| WebFlux, raw JSON, c256 | `%0,40 azalma` | `%8,19 azalma` | En fazla `+2,11 MiB` | `0` |

Bütün hücreler release sınırlarını geçti: kullanışlı RPS kaybı en fazla `%2`, p99 artışı en fazla
`%10`, process RSS artışı en fazla `3 MiB`. Tam WebFlux matrisindeki en yüksek RSS farkı
`+2,11 MiB` oldu. Standalone runtime yine tek exporter thread'ine sahiptir. Windows process
sayacında işletim sistemine ait ek bir socket helper thread'i görülebilir. Agent ikinci worker veya
Java executor oluşturmaz.

## Uyumluluk

Rust-Java REST `4.5.5`, REST ABI `29` ve Glowroot ABI `3` kullanın. Bu sürümde native telemetri
ABI'si değişmedi. İlgisiz sürümler arasında native binary kopyalamayın.
