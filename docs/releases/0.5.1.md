# java-rust-glowroot-agent 0.5.1

[English](0.5.1.md) | [Turkish](0.5.1.tr.md)

`0.5.1` makes container packaging failures visible and prevents a shared dependency layer from
silently disabling the Spring agent.

## What Changed

- Startup now prints a native-runtime readiness line after the Java package and ABI `4` library are
  active.
- `spring.application.name` is used automatically when an agent-specific application name is not
  configured.
- `scripts/verify-container-runtime.sh` checks the final container filesystem, classpath index,
  selected server adapter, native library, and unresolved Linux dependencies.
- The README now covers images that delete `BOOT-INF/lib` and redirect dependencies to a shared
  `NEW_BOOT-INF` PVC.

## NMC Deployment Fix

Updating only `librust_glowroot_agent.so` is not sufficient. The final pod must also contain the
matching Maven dependency JARs. For a Jetty application using the umbrella starter, verify at least:

```text
java-rust-glowroot-spring-boot-starter-0.5.1.jar
java-rust-glowroot-spring-runtime-0.5.1.jar
java-rust-glowroot-spring-jetty-adapter-0.5.1.jar
```

If the image removes `BOOT-INF/lib`, publish these JARs into the dependency image or shared PVC path
referenced by `BOOT-INF/classpath.idx`. Do not copy only the starter JAR; it is not a standalone
runtime.

## Expected Startup Evidence

```text
Java-Rust Glowroot native telemetry active: abi=4, profile=diagnostic, application=nmc-store-common
Java-Rust Glowroot HTTP telemetry active: adapter=jetty-request-log, transaction-type=Web
```

No first line means the runtime JAR or native library is not active. No second line means the HTTP
adapter is not active. When both lines exist, wait for the 60-second export interval and inspect
`diagnosticsJson()` if Central remains empty.

## Verification

The exact Spring Boot `3.2.4` + Jetty + Semeru OpenJ9 21 environment produced:

| Evidence | Result |
| --- | ---: |
| Collector init messages | `1` |
| Aggregate messages | `1` |
| Exact `Web` transactions | `102` |
| `/api/small` transactions | `100` |
| Gauge values | `20` |
| Validation errors | `0` |

This is a Java and deployment-guard patch. Glowroot native ABI remains `4`; the release reuses the
same GLIBC `2.17`-compatible DLL/SO as `0.5.0`.
