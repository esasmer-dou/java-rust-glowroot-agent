# java-rust-glowroot-agent 0.4.1

[English](0.4.1.md) | [Türkçe](0.4.1.tr.md)

`0.4.1`, Linux native uyumluluk patch sürümüdür. Telemetri sözleşmesini, Java entegrasyonunu,
runtime profillerini, thread sayısını, bellek sınırlarını, REST ABI'yi veya Glowroot ABI'yi
değiştirmez.

## Neler Değişti?

- Linux x64 agent artık sabit `glibc 2.17` sembol sınırıyla link edilir.
- CI, daha yeni bir GLIBC sembolü isteyen native dosyayı reddeder.
- CI, release `.so` dosyasını Debian Stretch (`glibc 2.24`) ve Debian Bookworm (`glibc 2.36`)
  içinde yükler.
- Native provenance bilgisine `linux-x64.glibc-minimum=2.17` alanı eklendi.
- Maven paketi ve GitHub Release kontrolü GLIBC sembol kapısını yeniden çalıştırır.

Önceki `0.4.0` Linux dosyası, GitHub runner'ın güncel linker yüzeyini devralıyordu. Bu nedenle
`GLIBC_2.34` sürümüne kadar sembol isteyebiliyordu. Bu dosya Debian Stretch gibi eski enterprise
image'larında yüklenemez. `0.4.1` dosyası `GLIBC_2.17` sürümünden daha yeni sembol istemez.

## Sürüm Yükseltme

Spring Boot uygulamasında seçtiğiniz agent paketini `0.4.1` sürümüne yükseltin:

```xml
<dependency>
  <groupId>com.reactor</groupId>
  <artifactId>java-rust-glowroot-spring-boot-starter</artifactId>
  <version>0.4.1</version>
</dependency>
```

Native dosyayı ayrıca kopyalıyorsanız `0.4.1` release dosyasıyla değiştirin. Uygulamadaki yol aynı
kalabilir:

```text
/u01/applications/nmc-store-common/glowroot/librust_glowroot_agent.so
```

Deployment öncesinde final image içinde şu kontrolü yapın:

```bash
getconf GNU_LIBC_VERSION
ldd /u01/applications/nmc-store-common/glowroot/librust_glowroot_agent.so
```

Yalnız builder aşamasını kontrol etmeyin. Builder ve final aşamalarında aynı değiştirilemez custom
JRE image'ını veya digest'ini kullanın.
