# java-rust-glowroot-agent 0.2.1

Bu stable patch, desteklenen iki çalışma modeli arasındaki son release kanıtı eksiğini kapatır. Java
business kodu ve kullanıcıya açık telemetri ayarları değişmez.

## Neler Değişti?

- Rust-Java REST artık Spring Boot MVC ile aynı exact-commit production gate'e sahiptir.
- REST gate, `rust-java-rest:4.4.1` sürümünü sabitler. Native ABI `28` değilse testi durdurur.
- Spring Boot starter, temiz `rust-spring v4.4.2` standalone binary dosyalarını paketler. 40
  karakterli tam kaynak commit'i ve platform SHA-256 hash bilgilerini kaydeder.
- Küçük JSON, raw veya önceden hazırlanmış JSON ve heavy JSON endpoint'leri c64/c256 altında altı
  eşleştirilmiş tekrar ile ölçülür.
- Telemetri kapalı ve açık varyantlar, seçilen aynı fiziksel CPU üzerinde sıralı çalışır.
- REST embedded telemetri `+3 MiB` sınırında kalmalı, yeni işletim sistemi thread'i eklememeli,
  yeni non-2xx cevap üretmemeli ve tanımlanan RPS/p99 sınırlarını geçmelidir.
- Glowroot wire uyumu, collector kapalıyken fail-open davranışı ve opsiyonel `-javaagent` bootstrap
  zorunlu release kontrolleridir.
- Spring ve REST kanıtları exact tag commit üzerinde birlikte geçmeden Maven deploy ve GitHub
  Release çalışmaz.

## Desteklenen Birlikte Kullanımlar

| Uygulama | Dependency | Native runtime |
| --- | --- | --- |
| Rust-Java REST | Yalnız `-javaagent` biçimi gerekiyorsa `com.reactor:java-rust-glowroot-agent:0.2.1` | `rust-java-rest:4.4.1`, REST ABI `28` |
| Spring Boot Servlet MVC | `com.reactor:java-rust-glowroot-spring-boot-starter:0.2.1` | Paketteki standalone Glowroot ABI `1` runtime |

En düşük bellek kullanan Rust-Java REST kurulumu yine doğrudan `reactor.glowroot.*` property'lerini
kullanır. Bootstrap JAR zorunlu değildir. Spring WebFlux ile tam Glowroot bytecode, JDBC ve profiler
instrumentation bu odaklı agent'ın kapsamında değildir.
