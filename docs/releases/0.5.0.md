# java-rust-glowroot-agent 0.5.0

[English](0.5.0.md) | [Turkish](0.5.0.tr.md)

`0.5.0` makes bounded HTTP telemetry visible in the existing Glowroot transaction dashboards while
keeping trace detail optional and bounded.

## What Users Get

- Every completed HTTP request contributes exactly once to **Average**, **Percentile**,
  **Throughput**, and **Errors**.
- Transactions use type `Web`, route-only names such as `/orders/*`, and the `http request` root
  timer expected by Glowroot Central.
- `reactor.glowroot.http.sample-rate` controls only optional trace detail. It no longer removes
  successful requests from endpoint totals.
- Route-cardinality overflow is grouped under `<route-limit-exceeded>` instead of disappearing.
- Startup prints the active Spring HTTP adapter, for example:

```text
Java-Rust Glowroot HTTP telemetry active: adapter=tomcat-valve, transaction-type=Web
```

Tomcat, Jetty, Undertow, portable Spring MVC, and WebFlux keep their separate optional adapter paths.
The Java application model and the existing Glowroot Central/Cassandra deployment do not change.

## Compatibility

| Component | Version or contract |
| --- | --- |
| Agent packages | `0.5.0` |
| Rust-Java REST | `4.6.0` |
| REST native ABI | `29` |
| Glowroot native ABI | `4` |
| Linux native baseline | GLIBC `2.17` |

Use all Java modules and the DLL/SO from this release together. An ABI `3` binary is rejected during
startup. Applications that also load `java-rust-cache` in the same process should use `0.7.6`.

## K8s Verification

1. Deploy the matching `0.5.0` package and native file.
2. Confirm the startup line names the expected adapter and `transaction-type=Web`.
3. Send traffic to at least two mapped routes.
4. Wait for one export interval; the default is 60 seconds.
5. Open Glowroot **Transactions**, select **Web**, and compare route totals with the requests sent.

The Windows DLL and Linux SO were built from clean `rust-spring v4.6.0` revision
`0ec9c9df091f225d3e78e6ced4f9b118dd9ba73c`. The release workflow verifies SHA-256 provenance and
the GLIBC 2.17 symbol ceiling before publishing.
