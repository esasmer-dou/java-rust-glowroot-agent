# java-rust-glowroot-agent 0.5.1

[English](0.5.1.md) | [Türkçe](0.5.1.tr.md)

`0.5.1`, container paketleme hatasını görünür hale getirir. Ortak dependency katmanının Spring
agent'ını sessizce devre dışı bırakmasını engelleyen bir kontrol sunar.

## Neler Değişti?

- Java paketi ve ABI `4` native kütüphane etkin olduktan sonra startup sırasında native runtime
  hazır bilgisi yazılır.
- Agent'a özel uygulama adı verilmezse `spring.application.name` otomatik olarak kullanılır.
- `scripts/verify-container-runtime.sh`; son container dosya sistemini, classpath index'ini, seçilen
  sunucu adaptörünü, native kütüphaneyi ve eksik Linux bağımlılıklarını kontrol eder.
- README, `BOOT-INF/lib` dizinini silip dependency'leri ortak `NEW_BOOT-INF` PVC'sine yönlendiren
  image'lar için genişletildi.

## NMC Deployment Düzeltmesi

Yalnız `librust_glowroot_agent.so` dosyasını güncellemek yeterli değildir. Son pod içinde eşleşen
Maven dependency JAR'ları da bulunmalıdır. Umbrella starter kullanan Jetty uygulamasında en az şu
dosyaları doğrulayın:

```text
java-rust-glowroot-spring-boot-starter-0.5.1.jar
java-rust-glowroot-spring-runtime-0.5.1.jar
java-rust-glowroot-spring-jetty-adapter-0.5.1.jar
```

Image `BOOT-INF/lib` dizinini siliyorsa bu JAR'ları `BOOT-INF/classpath.idx` dosyasının gösterdiği
dependency image'ına veya ortak PVC dizinine koyun. Yalnız starter JAR'ını kopyalamayın. Starter tek
başına çalışan bir runtime değildir.

## Beklenen Startup Kanıtı

```text
Java-Rust Glowroot native telemetry active: abi=4, profile=diagnostic, application=nmc-store-common
Java-Rust Glowroot HTTP telemetry active: adapter=jetty-request-log, transaction-type=Web
```

İlk satır yoksa runtime JAR'ı veya native kütüphane aktif değildir. İkinci satır yoksa HTTP adaptörü
aktif değildir. İki satır da varsa 60 saniyelik gönderim aralığını bekleyin. Central hâlâ boşsa
`diagnosticsJson()` çıktısını inceleyin.

## Doğrulama

| Kanıt | Sonuç |
| --- | ---: |
| Collector init mesajı | `1` |
| Aggregate mesajı | `1` |
| Tam `Web` transaction sayısı | `102` |
| `/api/small` transaction sayısı | `100` |
| Gauge değeri | `20` |
| Doğrulama hatası | `0` |

Bu sürüm Java ve deployment kontrolü içeren bir patch'tir. Glowroot native ABI `4` olarak kalır.
Sürüm, `0.5.0` ile aynı GLIBC `2.17` uyumlu DLL/SO dosyalarını kullanır.
