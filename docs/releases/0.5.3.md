# java-rust-glowroot-agent 0.5.3

[English](0.5.3.md) | [Turkish](0.5.3.tr.md)

`0.5.3` fixes the transaction interval that could be lost when Glowroot Central rotated a retained
HTTP/2 connection at its 20-minute maximum age. Java controllers, services, validation, Dubbo
clients, and business logic are unchanged. Glowroot native ABI remains `6`.

## What Changed

| Stage | New behavior |
| --- | --- |
| Before snapshot | The exporter replaces its connection after 15 minutes and checks readiness before draining counters. |
| Close race | The same protobuf bytes are retried after reconnect and collector init. |
| Before ACK | One bounded aggregate batch remains owned by Rust. It is not counted as delivered. |
| Longer outage | The pending batch stays bounded; newer transactions continue in preallocated counters. |
| Recovery | Central ACK releases the batch and `pending_aggregate_transactions` returns to zero. |

## Spring Boot Dependency

```xml
<dependency>
  <groupId>com.reactor</groupId>
  <artifactId>java-rust-glowroot-spring-boot-starter</artifactId>
  <version>0.5.3</version>
</dependency>
```

Use the DLL/SO packaged by `0.5.3`. Do not keep the `0.5.2` native file in a shared image layer.

## Production Check

Monitor these diagnostics fields:

- `collector_rotations` should increase around 15 minutes.
- `collector_request_retries` can increase for a close race or transient failover.
- `pending_aggregate_transactions` must return to zero after recovery.
- `dropped_transactions`, `dropped_intervals`, and `last_error_code` must not increase for a
  recovered rotation.

The retry state is in memory and bounded. It covers Central connection rotation and transient
transport failures. It is not a process-crash durable queue; that would require a disk WAL and a
different footprint contract.

## Verification

The native gate uses a local HTTP/2 collector that reads the first aggregate body and closes before
acknowledgement. The replacement connection receives the byte-identical payload, and the dropped
transaction counter remains unchanged. Linux binaries retain the `glibc 2.17` symbol ceiling.
